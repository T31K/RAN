# Custom item model credits

The Odyssey weapons (`make_odyssey.py`, items 0_25 .. 0_30) are built from these Sketchfab models,
all licensed **CC Attribution 4.0** (https://creativecommons.org/licenses/by/4.0/). The source
files are in `assets/custom-items/odyssey/<folder>/model.glb`, each with its `credit.txt`.
Changes made for the game: re-oriented, re-scaled and re-centred onto RAN's weapon frames, the
gauntlet mirrored to a right glove, flattened slightly and skinned to the Biped hand, textures
re-encoded as DXT1/DXT5 DDS, inventory icons rendered from the meshes.
